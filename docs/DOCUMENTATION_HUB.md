## 📝 Documentation Maintenance

### Adding New Documentation
1. Check if topic already exists
2. Follow [Documentation Standards](./DOCUMENTATION_STANDARDS.md)
3. Update this hub and [README.md](./README.md)
4. Add to appropriate category
5. Cross-reference related docs

### Updating Documentation
1. Update "Last Updated" date
2. Review and update cross-references
3. Verify SSOT compliance
4. Update documentation index if needed

### Archiving Documentation
1. Move to `docs/archive/[category]/[YYYY-MM]/`
2. Update cross-references
3. Update documentation index
4. Add deprecation notice if needed
